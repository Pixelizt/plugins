# Reviews
Use for: quotes you were given (a name and the words). Don't use for: invented testimonials, or Review / aggregateRating JSON-LD.
Vibe: any. Motion level: any.
Deps: none. Origin: original. License: agency-owned.
Props: `title?`, `intro?`, `items: { name, text, stars?, source?, date? }[]`.
An empty list renders nothing. Stars are text with an accessible name, clipped to 1–5.
The content-lists `reviews` section is the CMS-backed version of the same idea. Use that when the module is installed.
